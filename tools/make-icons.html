Générateur d'icônes PWA

Mode d'emploi :
  1. Sélectionnez votre logo (PNG ou JPG carré idéalement)
  2. Cliquez sur Télécharger 192 et Télécharger 512
  3. Placez les 2 fichiers dans public/icons/ du projet, puis git add icons/* && git commit && git push


Astuce : sur Windows, faites un clic-droit sur l'image téléchargée → propriétés pour vérifier les dimensions.
